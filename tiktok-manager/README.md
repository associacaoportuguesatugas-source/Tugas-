# TikTok Manager — TUGA

Estrutura de dados e regras para a gestão do TikTok da Associação Portuguesa TUGA.

- Ler `SPEC.md` antes de gerar, rever ou publicar qualquer conteúdo.
- `data/history.json` — histórico de publicações (importado da Postiz + novas entradas geridas por este sistema).
- `data/calendar.json` — fila de publicações preparadas, à espera de aprovação.

Sistema em **modo aprovação**: nada é publicado sem confirmação explícita do responsável da Associação.
